A one-line museum placard for an office keyboard, catalogued as an ancient artifact: its letters wore away first on E, A and S, the letters of every urgent email ever sent. Donated by a departing intern.

## Run it

```sh
python3 main.py
```

Writes the placard to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). Python standard library only; deterministic, same bytes every run.
